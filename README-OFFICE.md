# FT Office Lite

این نسخه برای استفاده روزمره همکاران اداره ساخته شده است. TensorFlow، ابزارهای
آموزش مدل و مرورگر پرتابل داخل بسته نیستند. برنامه از Microsoft Edge نصب‌شده
روی Windows استفاده می‌کند و در صورت در دسترس نبودن Edge، Google Chrome را
امتحان می‌کند.

## شروع سریع

1. ZIP را در یک پوشه ثابت استخراج کنید.
2. `Start-FT-Office.bat` را اجرا کنید.
3. نام کاربری و رمز را وارد و «شروع» را بزنید.
4. پس از ورود، محیط و پوشه‌های آپلود و دانلود را انتخاب کنید.

تشخیص CAPTCHA و ورود خودکار داخل برنامه انجام می‌شود. اطلاعات ورود فقط با
Windows DPAPI و فقط برای همان حساب Windows ذخیره می‌شود. مرورگر و پوشه برنامه
را تا پایان عملیات نبندید.

## نکات ایمنی

- فقط فایل‌هایی که نتیجه اسکن سالم آنها صریحاً تأیید شود وارد صف نهایی می‌شوند.
- فایل موفق پس از Queue نهایی به پوشه `_uploaded` منتقل می‌شود.
- پوشه‌ها بازگشتی پیمایش نمی‌شوند.
- فایل‌های موقت `.tmp`، `.part` و `.crdownload` آپلود نمی‌شوند.
- در صورت خطای کلی دانلود خودکار، پایش همان نشست متوقف می‌شود.

داده‌ها، تنظیمات، نشست مرورگر و Credential رمزگذاری‌شده در مسیر زیر نگهداری
می‌شوند:

```text
%LOCALAPPDATA%\ft-nioc-uploader
```

برای گزارش خطا، تب «خروجی و گزارش» را باز و «کپی کل» را انتخاب کنید.
